Learning Git & Github

Git Commands

Git Bash

  1. git --version : used to know which version of git user is using.
  2. git config --global user.name "" : used to give user name in git, "global" dictates that name is being saved globally.
  3. git config --global user.email "" : used to connect local editor to git using email.
  4. git config --list : used to get to know what all credential changes user has done.
  5. clear : used to clear the terminal.

VS code Terminal

  1. git clone <-link of repo-> : connects local code editor to git.
  2. cd : used to change directory
  3. ls : used to show list of files
  4. ls -hidden : used to show hidden list of files.
  5. git status : used to know about the status of the files

    6. There are four types of states of files:\n 1. Untracked: types of files that are unknown to git. \n 2. Staged: types of files which are ready to be committed. \n 3. Modified: types of files whose context have been changed. \n 4. Unmodified: types of files that remain unchanged.

  6. git add <-name of file-> : stages the specific file.
  7. git add . : adds all of the files to a staged position.
  8. git commit -m "a meaningful message": used to commit all the staged files.
  9. git push origin main - used to push all the commited files so as to show a change in our github repo

Create a new repository directly through local computer

    Using 'init'

  1. git init : used to create a new repository in local computer.
  2. git remote add origin <-link of repo-> : used to connect the local repository to a remote repository.
  3. git remote -v : used to verify the remote repository.
  4. git branch : used to create a new branch.
  5. git branch -M main : used to rename the branch to main.
  6. git push -u origin main : used to push the local repository to remote
